# 0.2.0

MCP `type_text` 先检查整段文本，再按最多 64 字符顺序输入，提供字符进度和汇总结果。每段保留 30 秒上限，整个调用最多 120 秒；中断或失败不重放文本。同一会话的其他输入在分段期间返回 CONTROL_BUSY，人工接管、取消和释放仍可用。MCP 宿主应允许超过 120 秒的调用；超时较短时每次提交不超过 64 字符。直接调用 HTTP 命令接口仍受单作业 30 秒限制。

修复键盘操作后的输入释放：当前所有者尚未使用鼠标时，`release_inputs` 仅释放键盘，避免猜测鼠标模式和位置；使用过鼠标时按实际报文模式及位置释放。取消和超时清理采用相同规则。

2026-11-09 已在目标开机条件下验证 stdio/本机 HTTP MCP、截图、键盘、相对鼠标、互斥与人工接管。当前目标的绝对鼠标模式虽设置回读成功，但没有可见输入响应，尚未通过验收，暂用相对模式。完整边界见源码中的开发验证记录。

本版本提供 SuperKVM / CH9329 类型选择、明确的串口与视频源选择、串口波特率和采集参数设置；新增设备详情、只读串口诊断、设备日志、视频低功耗选项、光标校正、原始分辨率 PNG 截图、显示分辨率/缩放/铺满、光标外观及滚轮偏好。Ctrl+Alt+Del 与 Alt+Tab 继续通过统一控制通道发送。

托盘及本机设置页可开启“保持本机唤醒”，默认关闭、允许熄屏，保存后随程序启动恢复，与局域网访问无关。连接偏好和电源偏好存入数据目录，发布包自带空 data 目录。

可靠性修复包括真实采集时间的新鲜度检查、有界帧投递与后台编码、采集异常和卡住检测、慢观看连接回收、视频 USB 身份匹配、控制请求 UUID 和幂等、串口最终授权校验、双向鼠标模式校验及默认测试硬件隔离。

本版本不包含音频、软键盘、录屏、剪贴板、Unicode 或文件扩展；固件升级、任意原始串口、USB 身份改写、U 盘方向及扩展板维护也不提供。设备返回无效状态的选项显示为不可用。

升级时先退出旧实例，再将完整 ZIP 解压到新目录运行 `Superuse.exe`。便携包内 `DEVICE-SETTINGS.md` 说明新增功能，`MCP.md` 说明接入；保留旧安装目录，按需迁移 data 中的配置。CH9329 尚无对应真机验证；LAN 本次验收使用本机局域网 IP，外部防火墙和网络连通性由部署环境决定。具体通过项见源码中的开发验证记录。
