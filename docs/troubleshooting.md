# 故障排查

| 现象 | 检查与处理 |
|---|---|
| 串口拒绝访问 / 视频设备被占用 | 在其他控制应用中断开连接，正常退出多余服务，再重试；Superuse 不会终止其他应用 |
| 未找到设备或匹配多台设备 | 执行 `superuse diagnose`；检查 USB 身份，在本机配置中指定 serial_number/device_path，保留配置隐私 |
| 绝对鼠标不能移动或落点不正确 | 切换“相对移动”，接管后点击画面捕获鼠标；相对计数不是屏幕像素 |
| Esc 后鼠标回到本机 | 这是释放鼠标捕获；控制权仍保留，再次点击目标画面即可继续 |
| 页面显示“人工暂停” | 失焦、隐藏、断连或租约过期会释放输入，但不交还 agent；选择“接管”继续或“交还”解除人工保留 |
| agent 得到 HUMAN_CONTROL | 等待人工显式交还，不循环抢占，也不删除人工保留状态文件 |
| agent 得到 CONTROL_REVOKED / STALE_BASIS | 重新获取状态和截图；需要时显式申请新租约，不重放旧输入 |
| 画面停更或显示过期 | 检查目标视频输出与 USB 连接；服务会拒绝普通输入，等待原设备恢复。驱动关闭挂起时正常重启应用 |
| ASCII 变成了其他字符 | 检查目标键盘布局、输入法和焦点；当前没有剪贴板或任意 Unicode 注入 |
| 帧率低、鼠标跟随滞后 | 查看实际 FPS、显示比例和帧龄；请求 30fps 不等于实际采集 30fps，提高 publish_fps 不能补出源帧 |
| 页面认证失效 | 从托盘“打开界面”获取新的打开链接，不复制旧 bootstrap 或运行文件中的令牌 |
| MCP 无法连接 | 先启动 broker，检查双方 runtime 目录一致；MCP 桥不会自行启动设备服务 |
| 重启后仍阻止 agent | 人工保留状态会持久化；在页面主动交还即可，不应通过删除文件绕过 |

提交问题时说明版本、控制端环境、设备型号、视频后端、操作步骤和错误码。附图前遮挡目标内容，不附串口序列号、完整设备路径、令牌或个人目录。来源与当前测试边界见[验证状态](development/validation.md)。
