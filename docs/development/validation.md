## 人工快速移动触发暂停的流控修复（2026-10-17）

- 运行日志连续记录 `input_backpressure_fence`，与快速移动触发、慢速移动不触发的反馈一致：相对位移报告产生速度超过逐条串口写入速度，填满服务端队列后执行释放屏障并保留人工 latch。
- 页面改为 4 条终态 ACK 发送窗口；等待期间累计相对位移，按钮/滚轮/键盘维持顺序。大位移在实际发送时拆包，失权时丢弃未发送输入；暂停界面区分失焦、积压和租约过期。
- 修复绝对移动合并误替换正在写入的报告，避免重复终态回执和后续报告丢失。可阻塞 fake writer 验证了这个竞态。
- 浏览器确定性回归覆盖 1000 次快速移动、慢写回执、大位移、顺序和断连清理；Python 源码回归 211 passed、6 deselected。为避免干扰正在使用的真实应用，本轮排除 Windows 单实例/打开页面及发布 EXE 启动测试；未向真实设备发送输入，也未停止用户程序。
- 新 ZIP 需退出旧程序、保留 data 后替换，并重新加载页面；尚需用户在实机复测快速移动体验。
