# 验证状态

这是公开的能力摘要，不包含具体目标系统、个人目录、设备序列号或截图。最后整理日期：2026-10-17。以下结果只代表对应环境和范围，不是跨设备/跨系统兼容性承诺。

| 范围 | 已验证 | 仍待验证 |
|---|---|---|
| 自动回归 | 契约、协议向量、竞态、模拟 broker、官方 MCP SDK、前端处理器、Windows 包冒烟 | 其他平台与更多客户端 |
| 真实视频 | 同一采集源供浏览器与 MCP，1920×1080 预览 | 更换固件/后端/分辨率后的兼容与性能 |
| 真实输入 | 相对移动、右键、ASCII、键盘组合键；创建测试文档、保存、关闭后重开核对内容 | 完整拖动/滚轮、所有按钮、DPI 与布局组合 |
| 协作 | 人工接管撤销旧输入、显式交还后 agent 可申请 | 原生捕获权限的全部交互与长期连续操作 |
| 分发 | 开发环境的 onedir 构建与 stdio 冒烟 | 干净无 Python 环境、签名、安装器 |

一次约 6 秒的真实预览采样为 60 帧，约 9.94fps，图像与源尺寸均 1920×1080；编码元数据帧龄中位数约 15ms、最大约 110ms。它不是端到端响应延迟，也不是五分钟性能或 60 分钟稳定性验收。当前链路约 10fps，不能将请求 30fps 写成实际能力。

2026-10-17 整理后的回归为 125 passed、8 deselected（约 34 秒）；8 项为 6 个硬件用例和 2 个会打开页面的 Windows 用例。契约/链接/许可、Ruff、前端处理器、Git 索引发布检查与本地 Windows 构建通过。已有 aiohttp bare-function 弃用提示仍需后续维护。此记录不是持续更新的 CI 徽章，后续提交应以实际执行为准。

已知限制：恢复到 human_hold 时，启动健康等待可能仍等满约 15 秒并记录不准确的健康警告；HTTP/视频可以已经 ready。此项与长稳、热插拔、更多浏览器兼容性应继续补充回归。

完整验收方法见[测试与验收](testing.md)。实机报告只记录脱敏结论；截图、原始日志和真实配置保留在仓库之外。
