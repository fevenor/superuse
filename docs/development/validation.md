# 验证状态

这是公开的能力摘要，不包含具体目标系统、个人目录、设备序列号或截图。最后整理日期：2026-10-17。以下结果只代表对应环境和范围，不是跨设备/跨系统兼容性承诺。

| 范围 | 已验证 | 仍待验证 |
|---|---|---|
| 自动回归 | 契约、协议向量、竞态、模拟 broker、官方 MCP SDK、前端处理器、Windows 包冒烟 | 其他平台与更多客户端 |
| 真实视频 | 同一采集源供浏览器与 MCP，1920×1080 预览 | 更换固件/后端/分辨率后的兼容与性能 |
| 真实输入 | 相对移动、右键、ASCII、键盘组合键；创建测试文档、保存、关闭后重开核对内容 | 完整拖动/滚轮、所有按钮、DPI 与布局组合 |
| 协作 | 人工接管撤销旧输入、显式交还后 agent 可申请 | 原生捕获权限的全部交互与长期连续操作 |
| 分发 | 开发环境的 onedir/portable ZIP 构建、迁移与 stdio 冒烟 | 干净无 Python 环境、签名、安装器 |

一次约 6 秒的真实预览采样为 60 帧，约 9.94fps，图像与源尺寸均 1920×1080；编码元数据帧龄中位数约 15ms、最大约 110ms。它不是端到端响应延迟，也不是五分钟性能或 60 分钟稳定性验收。当前链路约 10fps，不能将请求 30fps 写成实际能力。

2026-10-17 整理后的回归为 125 passed、8 deselected（约 34 秒）；8 项为 6 个硬件用例和 2 个会打开页面的 Windows 用例。契约/链接/许可、Ruff、前端处理器、Git 索引发布检查与本地 Windows 构建通过。已有 aiohttp bare-function 弃用提示仍需后续维护。此记录不是持续更新的 CI 徽章，后续提交应以实际执行为准。

portable 迭代将路径发现集中到托盘/CLI/MCP 共用模块，并修正健康 human_hold 启动仍等待超时的判定；恢复保留状态不等于恢复会话或输入任务。迁移与长稳、热插拔、更多浏览器兼容性分别验证。

## Portable 构建验证（2026-10-17）

- 新的 Windows x64 ZIP 约 94MiB，包含两个 EXE、依赖、空 data 目录、示例配置、原始许可、57 个构建环境 distribution 的许可清单与 SHA-256 文件；只收集许可，不复制安装环境的配置或 metadata 中的私人直接安装路径。
- 解压真实 ZIP 后，以模拟设备从其他 cwd 启动，官方 MCP stdio 客户端在无 runtime 参数时自动连接；迁移到含中文/空格路径后重启，instance/凭据轮换、人工保留状态持续、owner 为空，未写入测试 profile 的 AppData。
- 审查修复了无界面启动失败弹窗、broker 启动异常返回成功、初始配置未完整写入即对外可见的问题。失败启动会清理部分资源并返回非零退出码；构建还会拒绝目录链接和无效的 EXE 条目。
- 修复后以新 ZIP 解压副本运行完整回归，146 passed、8 deselected、约 42 秒；排除 6 项硬件和 2 项会打开默认浏览器的 Windows 用例。Ruff、48 契约用例、71 文档链接、3 项上游许可、前端处理器、发布树启发式检查通过；已有 aiohttp 弃用提示 198 项。
- ZIP CRC、空 data 目录、文件清单及本机项目/用户目录路径比对通过；两个 EXE 内的项目 Python 模块文件名也未包含本机路径。源码 tar/wheel 和 portable ZIP 分别检查；运行过的验证副本不再用于重新发布。
- 此次没有发送真实设备输入，没有在 GitHub 触发工作流或上传 release；同一开发主机的路径迁移不等于干净机器、跨账户权限或所有 Windows 版本验收。
