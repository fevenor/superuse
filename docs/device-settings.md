# 设备、显示与电源设置

在本机页面打开“设备与诊断”。设置设备前会释放现有控制，修改完成后需要重新接管；局域网页面提供观看、控制、显示设置和截图，设备配置及本机电源只从本机入口修改。

## 连接

选择 SuperKVM 或 CH9329，配置本机串口波特率，并通过“扫描可用设备”明确选择串口和视频输入。SuperKVM 默认 2000000，CH9329 通常使用 9600，以实际设备配置为准。更改波特率只调整本机连接，不改写设备波特率。CH9329 仅使用兼容的键鼠报文，不发送 SuperKVM 扩展查询、模式设置或重启指令。

设备依照 USB VID/PID 和稳定序列号、USB 位置或视频路径匹配；多个候选时不会随意选择。已连接设备在当前运行期间会固定身份，断开后不会自动采用同型号替代品。需要更换设备时明确选择新设备并保存。没有稳定身份的接口不出现在可保存的选择列表中。

采集宽高和请求帧率与“显示设置”分开。请求参数不保证硬件实际支持，面板显示实际采集尺寸。视频就绪只表示采集卡输出帧，不能据此判断目标电脑是否开机或 HDMI 是否有信号。

## 显示、截图和校正

“显示设置”提供适应、铺满、原始大小、常用分辨率与自定义尺寸，支持 Ctrl + 滚轮缩放，并保存本页光标及滚轮偏好。显示分辨率只改变浏览器显示大小，不修改目标分辨率或 EDID。人工视频保留最大 4096 像素宽度；MCP 截图仍使用独立的宽度限制。

“截图”下载原始采集分辨率 PNG，文件由浏览器保存，broker 不保存画面。画面过期时明确失败。

“光标校正”用于画面内部存在黑边的情况。可手动填写有效桌面的左边距、上边距、宽度和高度，也可检测黑边后确认候选值。黑屏或缺少足够图像内容时自动检测拒绝猜测。校正对网页与 MCP 的绝对坐标一致生效；黑边上的坐标被拒绝。修改会使旧 basis 失效，需重新观察。校正只在当前采集尺寸下有效，更换来源或尺寸后清除；不自动裁剪截图。

## 本机唤醒与设备选项

“保持运行 Superuse 的电脑唤醒”也可从托盘切换。默认关闭；开启后创建 Windows SystemRequired 电源请求，允许显示器熄灭，与局域网开关、网页和目标机状态无关。程序退出后释放请求，不改写系统电源计划。手动睡眠、合盖及系统电池策略仍由 Windows 决定。

视频卡低功耗是 KVM 自己的设置，与本机唤醒不同；视频可能临时断开，可从本机关闭该选项恢复。鼠标微动由 KVM 在被控端产生鼠标活动。上述设置均查询读回；串口写入成功不等于目标收到输入。

USB VID/PID 分别显示 Target 和 Host 参数。此版本提供身份查看和显式连接选择，不改写设备 VID/PID：当前设备两侧身份相同，且部分波特率上报无效，身份改写后的重新枚举和恢复缺乏可靠验证。它与固件升级、任意原始串口发送一并排除。

## 诊断与保存

设备详情包括固件、硬件、引导版本、温度、运行状态、USB 参数和编译信息；无效上报波特率显示为未提供，与实际连接波特率分开。序列信息只在本机人工详情中显示。

串口面板共用现有连接，可查询信息、查看字节计数、启停设备日志、过滤、清空和手动导出。日志默认不接收、不落盘，最多保留最近 500 条；不记录普通键鼠报文正文。没有任意 HEX 发送、固件更新、bootloader 操作、UVM/扩展板维护或压力测试入口。

连接与电源偏好存入应用数据目录的 `state/preferences.json`，启动时覆盖配置文件的对应设置。便携包使用自身 `data`；新发布包不带开发或旧安装的偏好、日志、设备身份或凭据。显示偏好保存在各浏览器本地。
